Kernregel

A versatile programming language with German-inspired syntax, supporting interpreter and C++ VM execution modes. Features include classes, pattern matching, calculus, networking, assembly, and more.

◆ Language Overview

Kernregel (abbreviated as Kr) is a multi-paradigm programming language with German-inspired keywords. It supports two execution modes: an interpreter mode and a C++ VM mode. The language supports Unicode characters in function names, variable names, and identifiers. It features a rich set of built-in capabilities including object-oriented programming, functional patterns, calculus operations, database access, HTTP networking, and even inline 64-bit assembly.

The language was initiated on 2026-06-28 and is currently at version v0.0.19xx. Note that the VM mode may be less stable than the interpreter mode.

◆ Variables & Constants

Kernregel supports mutable variables (der), immutable constants (das), lazy variables (faul), aliases (des), and global variables (global). Variables are optionally declared — assigning a value without a prefix creates a mutable variable in the current scope.

Kr 
der x = 10                    // mutable variable
der zl: zahl = 10               // typed variable
das π = 3.14159                 // constant
faul lazy = 2 + 3               // lazy (evaluated on first access)
des m = x                        // alias
der arr = [1, 2, 3, 4]

x <-> b                          // swap two variables
global g = 1                     // global scope

der link, recht = obj            // destructuring assignment
der a = 1, b = 2                 // multiple assignment

Kernregel supports a rich set of operators including arithmetic, logical, bitwise, comparison, and pipeline operators:

Kr 
// Arithmetic

◆ Control Flow

Kernregel provides familiar control flow structures with German-inspired keywords. It supports both brace-style and indentation-style syntax (as long as indentation is consistent within a block):

Kr 
// If / Else If / Else
fa x > 15 {
    // condition true
} snfa x == 15 {
    // else if
} sonst {
    // else
}

// While loop
indes x > 0 {
    x -= 1
}

// Do-while loop
tu {
    zeig "Weiter? (ja/nein): "
    lies antwort
} indes antwort != "ja"

// For loop with range
fuer i = 0; i < 5; i++ {
    fa i == 2 { weiter }   // continue
    fa i == 3 { bruch }     // break
}

// Range iteration
fuer i in 0..10 sch 2 { // step by 2 }

// Foreach over array
fuer w in zahlen { // w = each element }

// Foreach over object key-value pairs
fuer k, w in obj { // k=key, w=value }

// Nested loop break/continue with depth
fuer i in 1..5
    fuer j in 1..4
        fa j == 2 weiter 2   // break 2 levels
        fa j == 3 bruch 2       // break 2 levels

◆ Functions

Functions in Kernregel are defined with the fkt keyword. The language supports default parameters, variadic arguments, memoized functions, asynchronous functions, closures, anonymous functions, and function expansion (spread operator):

Kr 
// Ordinary function with default parameters
fkt addiere(a = 1, b) {
    a + b                        // last expression is returned
}

// Variadic arguments
fkt printf(result, &args) {
    // ...
}

// Memoized function (cached results)
#fkt fib(n) {
    als n {
        0 => { gib 0 }
        1 => { gib 1 }
        _ => { gib fib(n-1) + fib(n-2) }
    }
}

// Async function
ac fkt fetchData(url) {
    gib { "data": "Ergebnis", "status": 50 }
}
future = fetchData("api")
// data = warte future

// Anonymous function & closure
verdopple = fkt(x) { x * 2 }

fkt macheZaehler() {
    z = 0
    fkt ink_() { z = z + 1; gib z }
    gib ink_
}
z1 = macheZaehler()
// zeig z1()  -> 1
// zeig z1()  -> 2

// Function spread
args = [1, 2, 3]
f(...args)

// Macro
makro Makro() { // macro body }

◆ Classes & Objects

Kernregel supports full object-oriented programming with classes, inheritance, access modifiers (oeffent public, privat private, schutz protected), constructors, and static members:

Kr 
klass Tier {
    oeffent name: zkt = "unbekannt"
    privat alter: gzl = 0
    stati zaehler: gzl = 0

    konstr(name, alter) {
        dies.name = name
        dies.alter = alter
        zaehler++
    }

    fkt sprich() {
        // instance method
    }

    stati fkt getZaehler(): gzl {
        gib zaehler
    }
}

// Inheritance
klass Hund(Tier) {
    privat rasse: zkt = "Mischling"

    konstr(name, alter, rasse)
        ober(name, alter)        // call parent constructor
        dies.rasse = rasse

    sprich()                     // override parent method
        // zeig dies.name + " bellt!"
}

tier = Tier("Allgemein", 5)
bello = Hund("Bello", 3, "Schäferhund")
bello.sprich()                 // "Bello bellt!"

◆ String Operations

Kernregel provides an extensive set of string manipulation methods, regex support, and powerful string interpolation:

Kr 
// String methods
s = "  Hallo Welt!  "
s.lae(n>()                       // character length
s.trim()                      // trim whitespace
s.hat("Welt")                 // contains substring
s.ab(2, 6)                     // slice [2,6)
s.gross()                     // uppercase
s.klein()                     // lowercase
s.wieder(3)                   // repeat 3 times
s.ers(/Welt/, "Erde")         // regex replace
s.teil(/[,，、;]/)              // regex split

// String interpolation
name = "Welt"
// zeig "Hallo {name}!"         -> "Hallo Welt!"
// zeig "{n:.2k}"              -> formatted number
// zeig "|{n:<8}|"              -> left-aligned padding
// zeig "{#FFFFFF} Farbe. {#end}" // colored output

// Raw strings
u_Text = u"\nabc{}\t"         // no escape, no interpolation
b_Text = b"\x19\x11"           // binary string

◆ Array Operations

Arrays in Kernregel are dynamic and come with a rich set of built-in methods including higher-order functions:

Kr 
arr = [5, 2, 9, 1]
arr.anf(4)                     // append
arr.sort()                     // sort in-place
arr.unique()                   // deduplicate
arr.teil(1, 3)                 // slice
arr.umk()                      // reverse in-place
arr.flach()                    // flatten nested arrays
arr.vereinige([6, 7])          // merge arrays
arr.schnitt([1, 3, 5])         // intersection
arr.differenz([1, 3, 5])      // difference
arr.mische()                   // shuffle

// Higher-order functions
arr.map(fkt(x) { x * 2 })           // map
arr.filter(fkt(x) { x % 2 == 0 })   // filter
arr.reduz(fkt(acc, x) { acc + x }, 0) // reduce
arr.zip([10, 20, 30, 40])          // zip arrays

// List comprehensions
quadrate = [ i*i fuer i in 0..5 fa i % 2 == 0 ]  // [0, 4, 16]

// Array spread
arr2 = [...arr, 4, 5]  // [1,2,3,4,5]

◆ Math & Calculus

Kernregel includes a powerful mathematical and calculus library with support for derivatives, integrals, equation solving, ODEs, and least-squares fitting:

Kr 
// Basic math
wurz(25)             // square root -> 5
btr(-10)             // absolute value -> 10
sin(0)               // sine
cos(0)               // cosine
lg(100)              // log base 10
ln(2.718)            // natural log
zuf()                // random number
setze(42)            // set random seed

// Derivatives
fkt quadrat(x) { gib x ^ 2 }
abl(quadrat, 2)       // first derivative at x=2 -> ~4.0
ab2(quadrat, 3)       // second derivative -> ~2.0
pabl(summe, [1, 2], 0) // partial derivative

// Integrals
inte(quadrat, 0, 1)       // trapezoidal integral -> ~0.333
simp(quadrat, 0, 1, 10)   // Simpson's rule
gauss(quadrat, 0, 1, 8)    // Gaussian-Legendre integral

// Root finding
nullst(sinx, 3, 4)        // bisection method -> ~3.14159 (pi)
newton(sinx, 3)            // Newton's method

// ODE solvers
euler(f_ode, 0, 1, 0.1, 10)    // Euler method
rk(f_ode, 0, 1, 0.1, 10)       // Runge-Kutta RK4

// Gradient descent
gradab(summe, [1, 2], 0.1, 100)  // gradient descent optimization

// Least squares fitting
datenpunkte = [{"x":0,"y":1}, {"x":1,"y":2.1}, {"x":2,"y":3.8}, {"x":3,"y":4.9}]
kquad(datenpunkte, 1)  // linear fit -> [c0, c1]
kquad(datenpunkte, 2)  // quadratic fit -> [c0, c1, c2]

◆ Exception Handling

Kernregel uses a try-catch-finally structure with German keywords:

Kr 
fkt divide(a, b) {
    ver {
        fa b == 0 {
            dem "Division durch Null"   // throw exception
        } sonst {
            gib a / b
        }
    } den fehler {              // catch block
        // zeig "Fehler: " + fehler
        gib -1
    } die {                     // finally block
        // cleanup
    }
}

// Assertions
sicher x > 0;
sicher (x != null);

◆ Enums & Pattern Matching

Kernregel supports algebraic data types with enums and powerful pattern matching:

Kr 
aufz Option {
    Einige(wert),              // variant with parameter
    Keine,                     // variant without parameter
    VAL_GZL,
    VAL_KOMMA,
    VAL_ARRAY
}

opt = Einige(42)

// Pattern matching
als opt {
    Einige(w) => {
        // zeig "Wert: " + w
    }
    Keine => {
        // zeig "Kein Wert"
    }
}

// Value matching
als 42 {
    42 => { // match }
    _  => { // wildcard }
}

// Destructuring match
als { "name": "arisu", "alter": 1 } {
    { name, alter } => { // zeig name + " ist " + alter }
}

◆ File Operations & Database

Kernregel provides file I/O, a built-in key-value database (KDB), JSON parsing, and process execution:

Kr 
// File I/O
lese("input.txt")                    // read file content
leseBin("img.png")                   // read binary file
schrd("out.txt", "Hallo")            // write to file
ausf("ffplay -nodisp -autoexit audio/1.ogg")  // execute command
lauf("C:\\test.exe", ["--h"])        // run program

// KDB Database
daten = ladeKD("test.kd")
eintrag = { id: 1001, text: "Alice Schmidt", daten: bytes("\x48\x65\x6C\x6C\x6F") }
schrKD(daten, eintrag)               // write record
eintrag = daten.hole(1001)           // read record
daten.suche("Projekt")              // full-text search
verschlKD(daten, "meinPasswort")     // encrypt database

// JSON
obj = jsonzu(`{"name": "Kernregel", "version": 1.23}`)
jsonStr = zujson({ name: "Test", zahl: 42 })

◆ Networking & Web Server

Kernregel has built-in HTTP client and server capabilities, supporting synchronous and asynchronous requests, routing, SSE (Server-Sent Events), and more:

Kr 
// HTTP Client
// Synchronous GET
erg = ANFR("GET", "https://httpbin.org/get", {
    kopf: { "User-Agent": "Kernregel" },
    zeitgre: 5
})

// Synchronous POST
antwort = ANFR("POST", "https://httpbin.org/post", {
    daten: "{"name":"test"}",
    kopf: { "Content-Type": "application/json" }
})

// Asynchronous GET
z = ac_ANFR("GET", "https://httpbin.org/get", { zeitgre: 10 })
res = warte z

// Web Server
fkt handler(anfrage) {
    fa anfrage.pfad == "/" {
        gib html(`<h1>Hallo Welt!</h1>`)
    }
    sonst {
        gib text("Nicht unterstützt", 405)
    }
}
starteServer(8080, handler)

◆ C++ Interoperability

Kernregel can execute C++ code directly and exchange data with it. The cpp() function compiles and runs C++ code, with support for binding Kr variables and JSON data exchange:

Kr 
name = "Welt"
zahlen = [1, 2, 3]

c_erg = cpp(`
#include <iostream>
int main() {
    std::string name = KR::get(input, "name").as_string();
    JSON output;
    output["gruss"] = "Hallo " + name + "!";
    std::cout << output.serialize() << std::endl;
    return 0;
}
`, {
    "mode": "json",
    "bind": { "name": name, "zahlen": zahlen },
    "timeout": 5000
})
zeig c_erg.gruss   // "Hallo Welt!"
zeig c_erg.summe   // 6

◆ 64-bit Assembly (VSE)

Kernregel includes a built-in 64-bit assembly language (VSE Standard Architecture) that can be executed directly. It supports registers, arithmetic, bitwise operations, control flow, stack operations, and system calls:

VSE Assembly 
<--va-->
_start:
    der r1, 42              // r1 = 42
    der r2, 100             // r2 = 100

◆ Preprocessor & Lexical Macros

Kernregel features a powerful preprocessor with conditional compilation, macros, platform detection, and lexical aliasing (keyword remapping):

Kr 
// Conditional compilation
#makro DEBUG 1
#fa DEBUG
    zeig "Debug mode"
#snfa LINUX
    zeig "Running on Linux"
#sonst
    zeig "Unknown system"
#endfa

// Macros with parameters
#makro ADD(a, b) (a + b)
#makro GREET(name) "Hallo " + name + "!"

ergebn = ADD(3, 5)           // expands to (3 + 5)
nachricht = GREET("Anna")    // expands to "Hallo " + "Anna" + "!"

// Lexical keyword aliasing
lexikal {
    "let"               = "der"
    "function"          = "fkt"
    "class"             = "klass"
    "if"                = "fa"
}

◆ Additional Features

Pointer Operations

Raw pointers (zgr<T>) and smart pointers (schlau<T>) with manual memory management.

  • zgr(value) - create raw pointer
  • schlau(value) - create smart pointer
  • zgrw(ptr) - dereference read
  • zgrs(ptr, value) - dereference write
  • frei(ptr) - free raw pointer

Type Introspection

Runtime type checking with typist() and .typ() methods, supporting basic types, arrays, objects, and functions.

  • typist(42) -> "gzl"
  • typist("hallo") -> "zkt"
  • typist([1,2]) -> "[gzl]"

Namespace & Modules

Import modules with imp, create named namespaces with umf, and use nutz to mark symbols as used.

  • imp "math.kr" as m
  • umf Namensraum { ... }
  • nutz x, y (suppress warnings)

Time & Random

Built-in time functions (zeit(), datum(), tick()/tock()) and random number generation (zuf(), setze()).

  • zeit() - Unix timestamp
  • datum() - date string
  • tick()/tock() - timer

Input & Output

Flexible I/O with zeig (print), lies (read), schr (print no newline), and formatted output with format().

  • zeigIn(stdfehl, "error") - stderr
  • lies e mit(/regex/) - read with regex
  • sleep(5) - delay

Verwirrt Sub-language

A symbol-based sub-language (<--vw-->) for concise expression-based programming without keywords.

  • Symbol-based syntax
  • Can call Kr functions/variables
  • Supports Unicode identifiers
